# GroundMap

Property Investigation & Land Management Platform

GroundMap is a web application designed to support property investigation, land research, and field survey workflows.

土地調査・案件管理・現地調査を効率化するために開発した個人プロジェクトです。

## Purpose

### English

GroundMap is a property investigation and land management platform designed to simplify land research workflows.

Users can manage investigation targets on a map, store registry information, attach field notes and photos, and generate PDF investigation reports.

### 日本語

GroundMapは土地調査・不動産調査業務を効率化するためのWebアプリケーションです。

調査対象を地図上で管理し、登記情報、現地写真、調査メモを一元管理できます。

さらに、保存した情報をPDF調査シートとして出力できます。
